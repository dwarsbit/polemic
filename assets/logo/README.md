# Logo explorations

Generated by `scripts/make-logo.py` from the geometry of `assets/polemic-logo.svg`,
with the caret enlarged to option D of `caret-sheet.html` (80% of the slash height, weight 7).
All text is converted to outlines, so the SVGs need no fonts installed.
Open `contact-sheet.html` (or `contact-sheet.png`) to compare everything at once.

Files are named `<style>-<treatment>.svg`.

Styles

- `lockup-tile`: the app tile next to "Polemic" in Inter Display SemiBold.
- `lockup-mark`: slash and cursor without the tile, next to the wordmark.
- `command`: `\polemic` set in JetBrains Mono, the slash drawn as in the icon, cursor after it.
- `outline`: line version of the tile, for print or single-colour use.
- `wordmark`: "Polemic" with the cursor as the last glyph, no mark.
- `pill`: the tile stretched into a pill with the wordmark knocked out.
- `ligature`: the slash stands in for the "l" in Polemic.
- `stacked`: tile above the wordmark, centred.

Treatments

- `color`, `color-dark`: brand gradient, pink cursor, for light and dark backgrounds.
- `gray`, `gray-dark`: zinc greys in place of the gradient.
- `mono-black`, `mono-white`, `mono-indigo`: one colour only; slash and cursor are knocked out of the tile.

Icon backgrounds (`icon-*.svg`, `icon-mauve-sheet.html`)

1024px icons in the macOS layout of `assets/app-icon.svg`, with the tile filled by
a vertical gradient in the mauve tints from `polemic-website/app/global.css` (or the
site's purple wallpaper colours) and a fine overlay grain, tuned to the grain level of
the site's wallpaper component.

Ink marks (`ink-*.svg`, `ink-sheet.html`)

Alternatives to the slash and caret, drawn as ink on the textured mauve tiles:
brush strokes, a wet-ink bleed, a drip, a splat, a drop, a nib, a spill and an
Instrument Serif italic P. The serif P needs the website's font, fetched with
`npm pack @fontsource/instrument-serif` and converted to TTF (see `FONTS` in the script).
