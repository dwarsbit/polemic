The **Assets** tab shows the images and PDFs in your project as a thumbnail grid.

## Importing

Import files into the project; they are copied into an `assets/` folder. Drag an asset
into the editor to insert a figure, or double-click it to insert it at the cursor with
the right relative path and a sensible width.

## Finding assets

- Search by name, folder or tag, and filter by file type.
- Tag assets to group them. Tags are stored in `.polemic/assets.json` in the project.
- Select an asset to see its dimensions, size, type, folder and date, and whether the
  document uses it.

## Image options

In the code editor, hover over an `\includegraphics` and click the cog, or

<kbd>Cmd/Ctrl</kbd> + click it, to edit its options (width, scale and so on) in a card.
